PROJETO 05 - Banco de Dados (CRUD Android SQLite)

Conteúdo do arquivo .ZIP:
1. res/layout/activity_main.xml -> Layout da interface com a correção de erros de sintaxe XML e botões para o CRUD.
2. java/com/example/projetocrud/BancoHelper.kt -> Classe SQLiteOpenHelper responsável pelo banco de dados (criar, cadastrar, consultar, atualizar e deletar).
3. java/com/example/projetocrud/MainActivity.kt -> Código em Kotlin para vincular a interface com o banco de dados e tratar os eventos dos botões.
